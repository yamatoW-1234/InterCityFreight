    About Project

    Project Overview

    FreightRoute is an Inter-City Freight Logistics & Infrastructure Network Planner built for the Design and Analysis of Algorithms (DAA) course. It models Indian highway corridors as a weighted directed graph and dispatches deterministic shortest-path and minimum-spanning-tree algorithms based on operational objectives.

    CourseDesign & Analysis of Algorithms (DAA)
    Core EnginePure C11 (Zero external runtime dependencies)
    Backend BridgeNode.js + Express REST API
    FrontendVanilla JS, Leaflet (OpenStreetMap), Chart.js
    Core Algorithmic Capabilities
    A* Search (Fastest Transit) Minimizes travel time using an admissible Haversine distance / max-speed heuristic.
    Dijkstra's Algorithm (Shortest / Non-Negative Cost) Backed by a custom AVL-tree indexed min-priority queue for O((V + E) log V) extraction.
    Bellman-Ford (Subsidized Financial Routing) Computes net cost (toll + fuel − subsidy) with negative edge weights and cycle detection.
    Prim's MST & B-Tree City Indexing Builds multi-hub highway backbones over metric closures and resolves city lookups in O(log n).
